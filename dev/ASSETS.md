- Changes: none. Each file was copied as is and renamed to the word id.
- Files: 166, listed below.

### Why this commit

At this commit the repository's `LICENSE` file is Apache 2.0 and its README says
"Tools and most image resources are under the Apache license, version 2.0".

On 29 July 2024 the repository's `LICENSE` file was replaced with the SIL Open Font
License 1.1 (commit `254596e5f8a7991229f4b8292eb3b7fa41662446`), while the README kept
the Apache wording, and the pictures moved from `svg/` to `2D/svg/`. The project owner
chose on 25 November 2026 to copy from the last commit before that change, where the
licence of the pictures is not in doubt. Pictures added to Noto Emoji after
February 2024 are not used.
